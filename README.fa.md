# اپ جلسهٔ آنلاین

جلسهٔ آنلاین رایگان و اختصاصی، روی سرور خودتان.

افراد در مرورگر وارد اتاق می‌شوند: صحبت می‌کنند، دوربین را روشن می‌کنند، صفحه را به اشتراک می‌گذارند، روی تخته می‌نویسند، فایل باز می‌کنند و چت می‌فرستند. گروه کوچک مستقیم از مرورگر به مرورگر وصل می‌شود. گروه بزرگ از سرور مدیایی استفاده می‌کند که همین نصب‌کننده می‌گذارد. حساب‌ها، اتاق‌ها، چت، ضبط‌ها و فایل‌ها در پایگاه دادهٔ خودتان می‌ماند.

[English](README.md)

## پیش‌نیازها

- اوبونتو، و یک شل root
- `git`. اگر نبود: `sudo apt-get install -y git`
- یک دامنه
- یک IP عمومی، و رکورد A دامنه روی همان IP، پیش از گرفتن گواهی
- پورت‌های بخش پورت‌ها، باز روی همان IP عمومی
- خروجی HTTPS، تا Let's Encrypt در دسترس باشد

نصب‌کننده Nginx، MariaDB، PHP، Coturn، LiveKit، certbot و ffmpeg را می‌گذارد. سایت‌های دیگر Nginx می‌مانند. فایروال فقط قانون جدید می‌گیرد.

## نصب

نصب روی سروری که IP عمومی دارد.

```bash
git clone --depth 1 --branch v1.1.1 https://github.com/mrkioumarsi/didar-free-online-meetings-app.git didar && sudo bash didar/install/didar-install.sh --net direct --domain meet.example.com --email you@example.com --admin-user admin --admin-pass 'your-password' --confirm-wipe
```

نصب روی سروری که پشت NAT است. پورت‌ها را به این ماشین فوروارد کنید.

```bash
git clone --depth 1 --branch v1.1.1 https://github.com/mrkioumarsi/didar-free-online-meetings-app.git didar && sudo bash didar/install/didar-install.sh --net nat --domain meet.example.com --email you@example.com --admin-user admin --admin-pass 'your-password' --confirm-wipe
```

اگر دامنه هنوز رکورد A ندارد، `--public-ip` را به دستور NAT اضافه کنید.

اولین خطی که چاپ می‌کند باید `Didar 1.1.1 installer 20261120-clone` باشد. اگر نیست، پوشهٔ `didar` را پاک کنید و دستور را دوباره بزنید.

`--confirm-wipe` همهٔ پایگاه‌داده‌های MariaDB روی همین ماشین را پاک می‌کند. سایت‌های دیگر Nginx می‌مانند. فایروال فقط قانون جدید می‌گیرد. بدون این فلگ، اسکریپت صبر می‌کند تا `WIPE-DATABASES` را بنویسید. رمز مدیر حداقل ۸ نویسه است. اگر `--admin-pass` را ننویسید، یک رمز ساخته می‌شود.

`SUCCESS` اول حالت مدیا را چاپ می‌کند، بعد رمز پایگاه داده، بعد نام کاربری و رمز مدیر. قبل از بستن ترمینال آن‌ها را بردارید. همان مقدارها در `/etc/didar/secrets.env` و `/etc/didar/admin.txt` است. رمز root ماریا چاپ نمی‌شود. `https://your-domain/` را باز کنید و وارد شوید.

بعد از نصب موفق، فایل‌های نصب از پوشهٔ سایت و از پوشهٔ استخراج پاک می‌شوند. دستورهای `didar-update` و `didar-reinstall` و `didar-uninstall` می‌مانند.

## به‌روزرسانی و نصب مجدد

به‌روزرسانی وقتی است که گیت‌هاب رلیز جدیدتری دارد. نصب مجدد همین رلیز را یک بار دیگر می‌گیرد. پایگاه داده، `config.local.php`، اتاق‌ها، ضبط‌ها و آپلودها می‌مانند.

```bash
sudo didar-update
sudo didar-reinstall
```

در تنظیمات هم همین دو کار هست. نصب اول اگر ناتمام مانده باشد با نصب مجدد درست نمی‌شود. رلیز را دوباره دانلود کنید و نصب‌کننده را اجرا کنید. این کار MariaDB را پاک می‌کند.

## پورت‌ها

این‌ها باید روی IP عمومی باز باشند. در حالت nat آن‌ها را به سرور فوروارد کنید.

- SSH، روی پورتی که همین ماشین از قبل استفاده می‌کند
- ۸۰ و ۴۴۳ روی TCP
- ۳۴۷۸ روی TCP و UDP
- ۵۳۴۹ روی TCP
- ۷۸۸۱ روی TCP
- UDP از ۴۹۱۵۲ تا ۴۹۹۹۹ و از ۵۰۰۰۰ تا ۶۰۰۰۰

خروجی HTTPS به Let's Encrypt باید باز باشد. اگر گواهی زمانش تمام شد، کمی صبر کنید و نصب‌کننده را دوباره اجرا کنید.

تماس را از اینترنت موبایل امتحان کنید. گوشی روی همان وای‌فای سرور اغلب نام عمومی را باز نمی‌کند.

LiveKit به یک آدرس واقعی سنجاق شده و `use_external_ip` خاموش است. در direct هر دو طرف Coturn کارت عمومی است. در nat آدرس عمومی اعلام می‌شود و رله از کارت خصوصی است. «فقط از طریق TURN» خاموش می‌ماند، مگر خودتان در تنظیمات روشن کنید.

بعداً در تنظیمات می‌شود گواهی خودکار ماند یا کلید خصوصی، کلید عمومی، گواهی و باندل را گذاشت. ذخیره، وب‌سرور را یک بار ری‌استارت می‌کند. اگر به حالت خودکار برگردید و آن گواهی نباشد، گواهی دستی سر جایش می‌ماند.

## حذف

```bash
sudo didar-uninstall --soft
sudo didar-uninstall --hard
```

`--soft` صبر می‌کند تا `REMOVE` را بنویسید. پایگاه داده، فایل‌ها، سایت، LiveKit، Coturn و گواهی دیدار پاک می‌شوند. Nginx، PHP، MariaDB، سایت‌های دیگر، SSH و UFW می‌مانند.

`--hard` صبر می‌کند تا `DELETE` را بنویسید. Nginx، PHP، MariaDB و همهٔ پایگاه‌داده‌ها، certbot، ffmpeg، گواهی‌های این سرور و قانون‌هایی که نصب‌کننده باز کرده هم پاک می‌شوند. SSH و خود UFW می‌مانند. وقتی پرامپت نیست `--yes` را کنارش بگذارید.

## داخل اتاق

میکروفون، دوربین، اشتراک صفحه، تخته و چت. برگهٔ فایل عکس، ویدیو و PDF را نگه می‌دارد. یادداشت روی فایل برای افراد اتاق زنده است و ذخیره نمی‌شود. افراد اتاق می‌توانند فایل را دانلود کنند. میزبان حذف می‌کند. وقتی میزبان صحنه، تخته یا یک فایل را باز کند، اتاق دنبال او می‌رود. ضبط از کارت همان اتاق پخش می‌شود. از تنظیمات می‌شود بکاپ کامل پایگاه داده گرفت.
